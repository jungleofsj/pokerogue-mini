# PokeRogue Mini

[PokéRogue](https://pokerogue.net) 공식 웹사이트를 작은 데스크톱 창으로 감싸는 Windows용 Electron 앱입니다.
"PC에 작게 띄워두고 틈틈이 즐기는" 용도에 맞춰, 브라우저로는 불가능한 편의 기능을 붙였습니다.

> 게임 코드는 일절 수정하지 않으며, 공식 서버에 그대로 접속합니다.
> 따라서 **계정 로그인과 세이브 연동이 정상 동작**하고, 폰/다른 PC와 이어서 플레이할 수 있습니다.

## ✨ 기능

| 분류 | 내용 |
|---|---|
| 🎨 화면 톤 | 컬러 / **흑백** / **세피아** 콤보박스 + 강도 0~100% 조절. 눈에 안 띄게, 또는 야간에 눈 편하게 |
| 🔆 밝기 | 게임 화면 밝기 20~100% (툴바도 함께 어두워짐) |
| 👻 창 투명도 | 창 전체 투명도 30~100% |
| 🔇 소리 | **기본 음소거.** 음소거를 풀어도 창이 비활성화되면 자동 음소거, 돌아오면 복원 |
| ⇄ 크기 프리셋 | 미니 모드(448px, 화면 우하단) ↔ 일반 모드(854px, 화면 중앙) 원터치 전환 |
| 📌 항상 위 | 창을 항상 다른 창 위에 고정 |
| 🫥 보스키 | 창을 흔적 없이 완전히 숨김 (작업표시줄에서도 사라짐, 자동 음소거) |
| 🔴 트레이 아이콘 | 시계 옆 몬스터볼 아이콘. 클릭 = 보이기/숨기기, 우클릭 = 메뉴 |
| ⌨️ 포커스 관리 | 툴바를 조작해도 키보드 포커스가 자동으로 게임에 돌아감 (Tab/Esc로도 이동) |
| 🌐 브라우저 창 | 🌐 버튼/`Ctrl+L`로 **별도 브라우저 창**을 엽니다 — 게임은 그대로 실행되면서 위키·월별 픽업 달력·공략을 열람. 주소창(검색어도 OK), ◀▶⟳, **Ctrl+휠 = 좌우 스크롤** |
| ✳ Claude 도우미 | 브라우저 창 왼쪽 사이드바 탭. 주력 포켓몬 기술배치 등을 Claude(Opus 5)에게 질문 — 웹 검색이 내장되어 최신 픽업/위키 정보도 조회합니다. **Anthropic API 키 필요(유료)** |
| 💾 설정 저장 | 창 크기/위치, 톤, 밝기, 투명도 등 모든 설정이 재시작 후에도 유지 |

툴바는 의도적으로 **완전 모노톤**으로 디자인되어 있고 네이티브 타이틀바 대신 타이틀바를 겸합니다(빈 공간 드래그로 창 이동). 게임 화면을 흑백으로 두면 앱 전체가 조용한 무채색이 됩니다.

## 📥 설치 및 실행

1. [Releases](../../releases)에서 `PokeRogueMini.exe`를 다운로드합니다.
2. 실행합니다. 설치 과정은 없습니다 (포터블).

> **참고**
> - 첫 실행 시 Windows SmartScreen 경고가 뜰 수 있습니다 (서명 인증서가 없는 개인 빌드라서). "추가 정보 → 실행"으로 진행하세요.
> - 포터블 exe는 실행할 때마다 임시 폴더에 압축을 풀기 때문에 **시작이 수 초 느립니다.** 매일 쓴다면 아래 "빠른 실행" 방식을 권장합니다.

### ⚡ 빠른 실행 (권장)

소스에서 직접 빌드하면 `dist/win-unpacked/` 폴더가 생기는데, 이 안의 `PokeRogueMini.exe`는 압축 해제 과정이 없어 **1~2초 만에 실행**됩니다.
폴더째 원하는 위치로 옮기고 exe 바로가기를 만들어 쓰세요.

## ⌨️ 단축키

| 키 | 기능 |
|---|---|
| `Ctrl+R` | 게임 페이지 새로고침 |
| `Ctrl+G` | 톤 켬/끔 (컬러 ↔ 마지막 사용 톤) |
| `Ctrl+M` | 음소거 토글 |
| `Ctrl+↑` / `Ctrl+↓` | 밝기 +5% / −5% |
| `Ctrl+←` / `Ctrl+→` | 투명도 −5% / +5% |
| `Ctrl+P` | 크기 프리셋 전환 (미니 ↔ 일반) |
| `Ctrl+T` | 항상 위 고정 토글 |
| `Ctrl+L` | 브라우저 창 열기 (주소창 포커스). 브라우저 창 안에서도 주소창 이동에 사용 |
| `Tab` / `Esc` | (툴바에 포커스가 있을 때) 게임으로 포커스 이동 |
| `Ctrl+Alt+P` | **보스키** — 숨기기/보이기. 전역 단축키라 다른 프로그램 사용 중에도 동작 |

숫자 값(`강`/`밝`/`투` 칩)은 **마우스 휠**로도 조절할 수 있고, 커서를 올리면 ▲▼ 버튼이 나타납니다.

## 🗂️ 데이터 저장 위치

모든 데이터는 `%APPDATA%\PokeRogueMini\`에 저장됩니다.

| 데이터 | 위치 |
|---|---|
| 앱 설정 (톤/밝기/창 크기 등) | `settings.json` |
| 로그인 세션, 게임 내 옵션 | `Partitions\pokerogue\` |
| 브라우저 창 쿠키/세션 | `Partitions\pokerogue-browser\` |
| 게임 진행/세이브 | 공식 서버 (계정 저장 — 앱과 무관하게 모든 기기 공유) |

> **Claude API 키**: 환경변수 `ANTHROPIC_API_KEY`를 읽거나, 사이드바에서 입력한 키를 `settings.json`에 **평문으로** 저장합니다. 공용 PC에서는 환경변수 방식을 권장합니다. API 사용량은 Anthropic 계정에 과금됩니다.

exe를 어디에 두고 실행하든 같은 데이터를 사용합니다. 앱을 완전히 초기화하려면 이 폴더를 삭제하면 됩니다.

## 🔨 소스에서 빌드

요구사항: Node.js 22+, npm

```bash
npm install
npm start          # 개발 실행
npm run dist       # dist/PokeRogueMini.exe (포터블) + dist/win-unpacked/ 생성
```

개발 팁: `npm start -- --test-profile`로 실행하면 별도 프로필(임시 폴더)을 사용해, 이미 실행 중인 본 앱의 로그인/설정을 건드리지 않고 테스트할 수 있습니다.

### 구조

```
main.js       # Electron 메인 프로세스 — 게임 창/트레이/단축키/설정/필터 적용
preload.js    # 게임 창 툴바 ↔ 메인 프로세스 IPC 브리지
toolbar.html  # 게임 창 상단 툴바 UI (모노톤, 반응형 줄바꿈)
browser.js    # 별도 브라우저 창 + Claude 채팅 백엔드 (@anthropic-ai/sdk, 스트리밍 + 웹 검색)
browser.html  # 브라우저 창 UI (주소창, 탭 사이드바, 채팅 패널)
browser-preload.js / web-preload.js  # 브라우저 창 IPC / Ctrl+휠 좌우 스크롤 주입
scripts/gen-icon.js  # 트레이용 몬스터볼 PNG 생성기
```

화면 필터(톤/밝기)는 게임 `WebContentsView`의 문서에 CSS `filter`를 주입하는 방식이라 게임 자체는 전혀 수정되지 않습니다.
